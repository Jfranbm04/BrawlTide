# BRAWL TIDE

Pingo es un valiente pinguino en una misión épica a través de desafiantes niveles 2D. Salta, corre y haz parkour para superar obstáculos. Usa tu pico para atacar a los enemigos o lánzales pelotas. Explora cada rincán para encontrar objetos ocultos y prepárate para el enfrentamiento final contra el jefe. Guía a Pingo a la victoria.

## Clonar y Ejecutar el Proyecto

Abre tu terminal (Git Bash, Command Prompt, PowerShell, o Terminal de Mac) y ejecuta el siguiente comando para clonar el proyecto en tu máquina:

```bash
git clone https://github.com/Jfranbm04/BrawlTide.git
```

---

### Abrir el Proyecto en Unity

Hay dos métodos para abrir el proyecto:

#### A. A través de Unity Hub (Recomendado)

1.  Abre **Unity Hub**.
2.  Haz clic en el botón **"Add"** en la esquina superior derecha.
3.  Navega hasta la carpeta donde clonaste el repositorio (donde se encuentra el directorio `/Assets`).
4.  Selecciona la carpeta raíz del proyecto. Unity Hub debería detectar automáticamente la versión requerida.
5.  Haz clic en el nombre del proyecto en Unity Hub para abrirlo.

#### B. Directamente con el Motor (Método Alternativo)

1.  Abre la versión de Unity requerida.
2.  Ve a **File \> Open Project** (Archivo \> Abrir Proyecto).
3.  Navega y selecciona la carpeta raíz del proyecto.

---

### 4\. Ejecutar la Escena Principal

Una vez que el proyecto se haya cargado en el Editor de Unity:

1.  Ve a la carpeta `/Assets/Scenes/`.
2.  Abre la escena principal del juego (**`MainMenu`**).
3.  Pulsa el botón **Play** para iniciar el juego.

## 🕹️ Controles del Jugador

| Acción                                | Tecla/Input                  |
| :------------------------------------ | :--------------------------- |
| **Movimiento Horizontal**             | Teclas A/D o Flechas Izq/Der |
| **Salto / Doble Salto**               | Barra Espaciadora (`Jump`)   |
| **Ataque Cuerpo a Cuerpo (Puñetazo)** | Clic Izquierdo del Ratón     |
| **Lanzar Bola**                       | Clic Derecho del Ratón       |
| **Pausa/Menú**                        | Tecla **Escape**             |
